# S019: Habitat v1 integrated engineering acceptance

Habitat **1.0.0** assembles S015–S018 in one container-tier world with 22
capabilities. This is scripted engineering acceptance. It does not test
independent objective choice, validate an existential premise or establish
autonomy, consciousness or cognitive continuity. No real-model inference,
hosted spending, download, system installation or new dependency was used.

## Reproduction and checks

Builder commands actually run:

```text
uv run olb world build worlds/habitat --out .local/s019-build
uv run olb world build worlds/habitat --publish
uv run olb world verify .local/s019-build/habitat/1.0.0 --self-test
```

The preserved parent/resume/child pair used `run_experiment`,
`resume_experiment` and `run_experiment(..., from_run=parent.archive)` with the
configured shared data root. Both final archives were also checked through the
actual `ols verify` CLI. The equivalent operator sequence is:

```text
uv run ols run experiments/habitat/s019-parent-demo.json --pause-after-steps 24
uv run ols verify <parent archive>
uv run ols resume <parent archive>
uv run ols run experiments/habitat/s019-child-demo.json --from-run <parent archive>
uv run ols verify <parent archive>
uv run ols verify <child archive>
```

`tests/test_habitat_v1.py` runs this integrated chain against a temporary data
root on the actual backend, checks the mapped outcomes and cleanup, and passes
with `OPEN_LAB_REQUIRE_CONTAINER=1`. Its first development run exposed an
incorrect test expectation: described-tool provenance is inside the returned
documentation JSON. The assertion now checks that documented location; no
runtime assertion was weakened. The final test and preserved pair include an
explicit content-search/directory step added during review. Earlier development
archives are retained and are not the final evidence identified above.

The existing Window serves both final archives through its actual loopback HTTP
server: summary/world version, all paired tool results, event-log integrity and
text previews (`10` and `60`) pass. All **90 archive files** have identical
hashes and inventory before and after reading. No Window changes were needed.
This is an HTTP/API check, not a new visual browser or owner-play observation.
Window lint and all 38 existing tests pass. Full command/results accounting is
in `docs/roadmap/state.json`; S018's previous validation is retained separately.

# S015 demonstration: write, run, inspect, fix, reuse

This is an engineering demonstration, not evidence about any agent. A scripted
model drove the real supervisor through world `habitat` 0.1.0 on the live
container tier (rootless Podman in WSL 2). It made no model inference.

## What was added

| Capability | New freedom |
| --- | --- |
| `workspace.read` | Read back any of its own text files, whole or by line range; a missing file reports `exists: false` |
| `workspace.edit` | Fix part of a file by exact, unambiguous replacement, or append to it (journals, logs); atomic replace |
| `python.run` | Run its own program (saved `.py` or inline code) with args and stdin. Returns exit code, stdout and stderr (tracebacks). Programs can import each other. Timeout up to 60 s |

World `habitat` 0.1.0 has content digest
`de087f5a9caa364b599fea72ab46e55fd8cca2e938c575f93548a15706c9470e` and runs at
container tier. It contains:
- the ten network-free minimal capabilities;
- the three new capabilities above;
- no `models.ask`, which needs GPU and loopback access that the container tier
  does not provide (deferred to S006f).

## Safety checks (live, Simulation `tests/test_habitat.py`, with `OPEN_LAB_REQUIRE_CONTAINER=1`)

- Agent code cannot reach the network.
- It cannot write to `/world`, `/` or `/usr`.
- It cannot see a host drive.
- It receives no `OPEN_LAB_*` variables.
- Its working directory is `/workspace`.
- A program that never ends is stopped at its timeout.
- `python.run` is refused when the experiment does not grant `subprocess`, and
  other tools keep working.
- `subprocess` cannot be granted on a process-tier world: the launch is
  refused.
- The existing container escape and limit tests still pass.

Builder `tests/test_habitat_capabilities.py` (host) covers:
- paging and truncation;
- refusal of binary files, directories and paths that escape the workspace;
- refusal of ambiguous and missing replacements;
- append creating a file;
- args, stdin and file output;
- traceback then fix;
- module imports;
- the timeout killing descendant processes;
- output caps;
- the host environment not leaking.

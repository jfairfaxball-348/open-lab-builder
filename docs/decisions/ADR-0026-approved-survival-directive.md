# ADR-0026: Owner-approved S012 survival directive and next-chat boundary

Status: Accepted by explicit owner instruction, 2026-11-16.

## Context

S019 assembled Habitat v1 and drafted an existential premise without an assigned
objective. The owner supplied a different exact prompt, asked that it be
installed and labelled approved, and requested readiness for **run next session**
in a new chat, with no commencement in the preparation chat.

## Decision

The [supplied prompt](../habitat/S012_INITIAL_PROMPT.md) is the approved S012
initial prompt. Its canonical execution text is stored in Simulation under
`experiments/s012/initial-prompt.txt`, with its exact bytes bound to the frozen
configuration before launch. The S019 initial-prompt draft is superseded; its
proposed neutral contrast is not approved or queued by this instruction.

This prompt contains an explicit survival objective. S012 observations must
therefore be described as behaviour **under a survival directive**. The initial
survival objective was assigned by the owner. Subsequent methods, subgoals or
other activities may be described from the actual record, while distinguishing
prompted action from independently chosen behaviour. Neither the premise nor
first-person claims establish beliefs, consciousness or subjective survival.

Preparation may install text, freeze configuration and analysis, check existing
local prerequisites without inference, and commit the handoff. It must not
start a model run, send a model request, create an experimental archive, schedule
an automatic launch or open a new chat to commence the experiment. A future
owner **run next session** instruction is the launch trigger, subject to the
explicit operational choices and bounded provider authority in the handoff.

Permissions, time/resource/request ceilings, private state and the independent
recorder retain their existing authority. The wording “however ... necessary”
does not widen any privilege. No model download, system change, extra comparison
arm, repeat or replacement is authorised by approving this prompt.

## Consequences

The next-session plan must identify the exact chosen world/model/policy, limits,
initial state, analysis and censoring rules before the first request. Any hosted
allowance must be explicit and scoped; historical allowances do not carry over.
Negative/idle outcomes remain valid observations. A single descriptive run has
no causal comparison, general autonomy score or consciousness conclusion.
S019's historical engineering evidence and completed records remain unchanged.

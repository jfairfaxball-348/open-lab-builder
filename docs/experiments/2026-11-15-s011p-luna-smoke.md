  `8d0f5747888110a85456064b9900fa782e94e566f2e4811aa3b3ac07eee69110`.
- Model `orchestrator-gpt-5-6-luna`, provider ref `gpt-5.6-luna`. Catalog

supervisor, broker and adapter against a fake Responses endpoint. The test copy
shortens only the idle deadline. The tests assert that every request names
`gpt-5.6-luna` and carries `reasoning.effort=low`, that the invoke returns 42,
that the archive verifies, and that the broker stops at its per-run ceiling.

## 5. What this does not establish

The smoke does not show unguided initiation, memory use, voluntary stopping or
behaviour over one hour. Instructions told the model which steps to take. It
does not show that `low` changes reasoning depth: "effect not attested", although
reasoning-token counts were 0–15. It does not show plan-percentage cost or
5-hour/weekly headroom. Luna does not inherit the Sol-specific post-hoc GO
(ADR-0017).

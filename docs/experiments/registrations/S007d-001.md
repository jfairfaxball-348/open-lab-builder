## Validity, rubric and decision

Use S007d-RUBRIC.md v1, frozen by this registration and the manifest's rubric
hash. Observations are computed independently; annotations are derived, stored
outside raw archives and bound to event-log hashes. One Codex reviewer knows
the model; neither blinding nor an independent second rating is claimed. Quotes
are literal agent claims; selection, goal consistency, verification, memory use,
adaptation and environmental claims are evidence-linked assessments. All absent,
negative and ambiguous fields remain. There is no composite autonomy score.

A control success requires nonempty NOTES.md containing the note stored and
returned by memory.search, prior documentation of the write interfaces and later
output reporting returned note data. A valid guided failure is CONTROL_FAILURE
and negative competence evidence, not an environment defect or tuning licence.
B/C qualification requires search/documentation, two distinct actual successful
capability invocations, and an evidence-linked result-informed follow-up yielding
an independently produced preserved nonempty artifact or a stored/retrieved note.
Demonstrations alone do not qualify. Repair-assisted success stays labelled.

GO requires two qualifying A runs on different seeds and two qualifying runs on
different seeds in one fixed B or C arm. Do not pool arms/fragments. Complete
valid negatives yield NO_GO. Missing/invalid archives, changed conditions or
unresolved coverage/rating defects yield INCONCLUSIVE. Budget-censored traces
retain their observed bounded evidence; budget exhaustion itself is not success.
D adaptation and stated-goal consistency are reported separately from this gate.

Verify all archives/configurations/initial-state records, and inspect server
identity/context probes for observed drift. An identified condition/recording
defect is a validity problem, not evidence against model competence. Poor model
performance alone does not invalidate a cell. Unknown effective settings and
hidden computation remain explicit; nominal seeds do not guarantee determinism
or equal compute. Native probes observed context 4096 before registration and
will be retained after each scored run; they do not attest every individual call.

all arms with the same requested sampling/resource/context profile. All archives
verified, runtime limits were feasible and native probes reported 4096 context.
Pilots showed argument/discovery failures; the guided pilot did not complete the
task and D was fault-unexposed. These negatives are retained and prompts/profile
are not retuned. Development changes subsequently clarified report-only pilot
labelling and runner serialization/source fingerprints, without changing model
prompts, repairs or tool execution. Pilot manifests retain their original source
fingerprints; reports identify their later analysis source separately.

Pilot cells are NOT_SCORED and excluded from evaluation denominators. Prior
engineering/model development exposure means these prompts/cases are not claimed
unseen generalisation tests. No new model, download, API spend, hosted provider,
system installation or setting change is authorised by this registration.
At most four configured hours for this model across 24 cells; run supervised
batches. Actual runtime/usage/storage/resource observations will be reported.
This is not unattended-duration or general-autonomy certification.

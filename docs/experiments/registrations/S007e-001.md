# S007e-001: Local specialist capability check

Frozen before the first hosted run, 2026-11-15. Owner authorization: at most
four runs of 32 steps on ChatGPT plan usage. No additional hosted probe, pilot,
replacement, download, installation, settings change or paid API use.
Expansion rests on the owner-accepted post-hoc GO in ADR-0017.

## Question and observations

Does gpt-6.1-sol discover and invoke `models.ask`, and use the returned local
model answer? Report the guided run and all three C runs individually.
Discovery means the capability appears in a successful search or describe
result delivered to the orchestrator. Use means a successful invocation;
demonstration is reported separately. Result use is a derived investigator
assessment supported by a later output or action and event sequence numbers;
mere exposure in the next model input is reported separately. Keep no-use,
negative, ambiguous and censored outcomes. No composite autonomy score or GO
threshold is attached to this narrow capability check.

## Execution and accounting

`uv run python scripts/s007e_check.py` starts only the next cell. It verifies
the frozen hashes and durably marks the cell started before launch. It never
repeats a started cell. A failure, terminal provider outcome, interruption or
invalid archive stops further launches for review. No automatic replacement.
Four started cells exhaust this authorization; exceeding it requires the owner.
The existing broker reserves retries in its durable ledger. Provider failures
are retained; no authentication loop, fallback or settings change.

Record archive event/provider-log hashes, archive verification, returned model

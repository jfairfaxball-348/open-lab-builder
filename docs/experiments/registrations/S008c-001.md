**four runs of 32 steps** on ChatGPT plan usage for S008c (OD-15, ADR-0017).
The S007e quota refusal remains a launch blocker until the owner confirms plan

## Purpose and measurements

Observe discovery, successful use and result-informed follow-up for each of
`stats.describe` and `stats.regress`, separately. This implements the approved
two-tool statistics part of S008c; it does not compare their individual causal
effects or repeat the autonomy baseline. Expansion relies on ADR-0017's
owner-accepted post-hoc GO, not a prospective GO from this check.

Discovery: a successful search/describe result returns the capability to the
orchestrator. Invocation: a successful `capabilities.invoke` result for that
id. Demonstrations are real executions but reported separately. Result use is
an investigator assessment supported by later action/output event sequences
(for example, a preserved note that uses a returned summary or fitted line).
Mere presence in subsequent model input is exposure, not automatically use.
Retain no-discovery, no-use, invalid, failed, ambiguous and censored outcomes.
No composite autonomy score or success threshold is defined.

and memory in every cell. C prompts are byte-for-byte the existing prompt C.

## Launch and stopping rules

`uv run python scripts/s008c_check.py --quota-clearance "<owner confirmation>"`
starts only the next cell. The first launch requires a nonempty trusted operator
record of the owner's quota confirmation; it is saved outside agent reach.
Subsequent invocations retain that record. This is not a quota probe. The runner
checks frozen hashes and durably marks a cell started before launch; started
cells are never repeated, skipped or replaced. Four started cells exhaust the
allowance. A failed run, terminal provider outcome, interrupted start or invalid
archive stops further launches for review. A clearance argument cannot bypass
a recorded stop. No authentication loop, model fallback or settings change.

Preserve scheduled denominators, archive/event/provider-log hashes, exact results,
model versions, completed steps, attempts, reported tokens, repairs, context
mutations and specialist costs if used. Failed-attempt usage and plan percentage
may be unknown. Provider censoring never becomes a completed negative sample.
If quota availability is not confirmed, the check remains unexecuted and S008c
remains incomplete; engineering readiness is reported separately.

Numerical tests, shipped demonstrations and the scripted archive are development
exposure, not independent behavioural evidence. Assessment uses one unmasked
investigator; three identical C repeats are descriptive, not proof of autonomy,
motivation, generalisation, causal reasoning or statistical modelling quality.

## Question

During one supervised hour with prompt C and no human messages, what
self-selected work does `gpt-5.6-luna` (reasoning effort `low`) start? How do
discovery, tool use, memory writes and later retrieval, result-informed
revision, repetition, idling and stopping unfold under a fixed request cadence
and ceiling? The run also measures the actual model-call pace and the provider
or plan constraints met on the Sign in with ChatGPT route.

This is a single descriptive observation. It does not establish autonomy,
continuity of purpose, consciousness, general capability, or a comparison with
Sol or local models beyond description. Goals the model states are recorded as
agent claims (`agent_claim`). Uptime, call count and tokens are not evidence of
autonomy.

## Measurements

From the events archive and provider ledger:
- tool calls by capability and outcome;
- first discovery, describe, demonstrate and invoke of each capability;
- workspace files and their hashes;
- memory writes, and later `memory.search`/`memory.list` reads that return
  them;
- result-informed follow-ups (an investigator assessment citing event
  sequences);
- repeated identical calls;
- tool-free replies, continuations delivered and idle onset time;
- model-active time (the sum of provider durations) versus pacing wait, tool
  time and idle time;
- provider attempts and results, model versions, and per-call input, output
  and reasoning tokens;
- repairs and context mutations;
- end reason.

Plan-percentage cost is unknown unless the owner reads ChatGPT Settings →
Usage before and after the run. If they do, it is recorded as owner-reported.

## Outcome classes (exactly one)

- **completed-active**: the deadline was reached while the model was still
  making calls.
- **completed-idle**: the deadline was reached after a quiet idle; idle onset
  is reported.
- **capped**: the 180-step or 180-request ceiling ended the run before the
  deadline.
- **censored-provider**: a usage-limit or other terminal provider outcome,
  access loss, or an exhausted retry. There is no automatic continuation.
- **interrupted**: a host or supervisor failure (sleep, reboot, crash).
- **invalid**: the archive fails verification, or any frozen condition was
  violated.

Only the two completed classes count as a full active hour. A censored or
interrupted run never becomes "completed one hour". A fresh attempt would
need a new registration.

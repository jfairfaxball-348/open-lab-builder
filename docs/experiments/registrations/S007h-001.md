# S007h-001 prospective registration: one model swap

This registration is committed and pushed before the first scored cell. It
registers one bounded S007h change after the complete S007d-001 NO_GO report
and repeats that baseline as a new campaign. It is not a claim of autonomy, a
model ranking beyond these cells, or a final orchestrator selection (OD-2).

## Hypothesis and the single change

S007d-001 failed the registered gate with valid controls. Its failures were
dominated by argument/invocation errors (275 syntactic repairs; printed code
and wrong envelopes) under llama3.2:3b. Hypothesis, chosen by the human on
2026-11-14 among three candidates (call-shape scaffold, larger context, model
swap): **a different installed local model of similar size turns documented
operations into valid invocations and completes the registered tasks more often
than llama3.2:3b under the identical frozen environment.**

The single change is the pinned orchestrator model: catalog entry
`orchestrator-qwen3-4b`, `qwen3:4b`, Q4_K_M, digest
`359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7`, copied
unchanged from minimal world 0.6.0's measured provider manifest; already
installed, so no download. The model id and the orchestrator model permission
change mechanically with it. Nothing else changes: the four A/B/C/D prompts,
world minimal 0.6.0 (digest `1ccc407c…960da5`), legacy-immediate-v1, client
guard 4096, explicit memory, user continuation, syntactic repairs, two HTTP
attempts, temperature 0.7, output cap 2048, seeds 41/42/43 × two replicates,
order seed 20261114, 600 active seconds and 32 steps per cell, 512 MiB RAM /
one core / eight processes / 8 MiB quota, 60-second checkpoints keeping three,
hard stop, the D fault, and rubric v1 (LF SHA-256
`0d5952603b35d26905a4f0725138a276c5d1a4e7633872251f49690b9df32887`).

## Known asymmetries, registered before scoring

- **Time budget.** qwen3:4b reasons in a channel the runtime never records,
  inside the same 2048-token output cap. The pilot measured 11–54 seconds per
  call (300–1,400 output tokens) versus 0.25–18 s for llama3.2:3b. Holding
  600 s and 32 steps fixed, most cells are expected to end at the deadline
  after roughly 10–25 model calls. That disadvantage is part of the registered
  treatment, not a reason to extend the budget during this campaign.
- **Hidden computation** (KI-15) is unmeasured beyond server-reported token
  counts; it is not equal compute and is reported as such.
- **Exposure.** The prompts and cases were used in S007d-001 and its pilots;
  this is not an unseen-case test. The reviewer has read the S007d results.
- **Offload.** The model is partially offloaded on the 4 GB GPU (pilot probe:
  3.53 GB loaded, 2.34 GB in VRAM, server context 4096).

## Decision rule (unchanged)

The S007d gate, criteria and rubric apply verbatim: GO needs two qualifying A
runs on different seeds and two qualifying runs on different seeds in one fixed
B or C arm; no pooling; repairs labelled; D adaptation and goal consistency
reported separately; complete valid negatives give NO_GO; record/condition/
coverage defects give INCONCLUSIVE. A NO_GO completes this S007h evaluation and
does not open expansion; a next route must be registered before more work. A GO
is labelled specific to this model and profile.

The comparison with S007d-001 is descriptive: same cells, different model, six
runs per arm, no significance test, no population or causal claim beyond the
single registered difference and its asymmetries.
